DESCRIPTION : This task focuses on developing a multithreaded chat application using Java based on the client–server architecture. 
In our solution, a central server is created using Java sockets to accept multiple client connections.
Each client is handled in a separate thread, which allows many users to send and receive messages simultaneously without interruption. 
Messages sent by one client are broadcast to all connected clients in real time.
This solution successfully demonstrates the use of socket programming, multithreading, and real-time communication in Java.
